# tucson-cast

2025년식 현대 투싼(ccNC)에서 Android Auto를 통해 폰의 앱을 차 화면에 띄우는 프로젝트입니다.
폰 화면은 독립적으로 유지되고, 차 화면 전용 가상 디스플레이에서 앱이 실행됩니다.

- [`docs/PRD.md`](docs/PRD.md): 제품 요구사항 문서 (v0.1 초안)
- [`phase0/`](phase0/): 기술 검증 앱 (Shizuku + Android Auto Car App Library). 빌드와 테스트 방법은 [`phase0/README.md`](phase0/README.md)

> 개인 테스트 단계입니다. 운전 중 영상 시청은 도로교통법 위반이므로 테스트는 정차 중에만 하세요.
